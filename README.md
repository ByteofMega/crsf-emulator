# CRSF Emulator: ESP32 + PyQt6 GUI

Эмулятор ELRS/CRSF-приёмника на ESP32: PyQt6-интерфейс отправляет RC-каналы
по WebSocket на ESP32, тот кодирует их в CRSF-кадры и шлёт по UART на FC
(Betaflight). Обратно ESP32 читает телеметрию FC (батарея, углы, режим
полёта, линк, GPS). GUI также умеет показывать карту Яндекса, вести
навигацию к точке с обратной связью по GPS и читать/писать настройки FC
(макс. скорость, угол наклона) через отдельный USB-провод к CLI.

## Структура
```
firmware/   — прошивка ESP32 (Arduino IDE)
gui/        — PyQt6-интерфейс (Python)
```
См. main.py — там три вкладки: Каналы, Карта, Настройки FC.

## Быстрый старт
1. Прошейте firmware/*.ino на ESP32 (впишите Wi-Fi в config.h).
2. `cd gui && pip install -r requirements.txt && python main.py`
3. Вставьте ключ Яндекс Карт в map.html вместо YOUR_API_KEY_HERE.
4. Настройки FC — через отдельный USB-кабель к самому FC (не через ESP32).

## Безопасность
- Автономная навигация — учебная демонстрация P-регулятора, не автопилот.
  Тестируйте со снятыми пропеллерами / в симуляторе перед реальным полётом.
- Нет failsafe при потере Wi-Fi — рекомендуется добавить таймаут в прошивку.
